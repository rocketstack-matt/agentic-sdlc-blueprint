# Decorator Standard (copy)

`control-evaluation.decorator.standard.json` is the
[control evaluation decorator Standard](https://github.com/finos/calm-schema/tree/main/standards/control-evaluation)
released in FINOS `calm-schema` (version 1.0), with `decorators.json`, the CALM 1.3 base decorator it extends. Both
are copied unchanged from `calm-schema`. Every decorator the gateway writes is validated against them.
